O que é um grafo?

Um grafo é uma estrutura formada por vértices (os pontos) e arestas (as ligações entre eles). Ele modela redes sociais, mapas, internet, rotas de entrega e muito mais.

Não direcionado
A aresta vale nos dois sentidos, como uma amizade.
Direcionado
A aresta tem sentido, como seguir alguém.
Ponderado
Cada aresta tem um peso, como a distância entre cidades.

Como guardar um grafo na memória

O grafo abaixo é o mesmo da simulação. Veja as duas representações mais usadas:

Matriz de adjacência

1 = existe aresta. Consulta rápida, mas gasta V² de memória.

Lista de adjacência

Guarda só os vizinhos. Economiza memória em grafos esparsos.

typedef struct grafo {
    int nro_vertices;
    int **arestas;   // matriz de adjacência
    int *grau;
} Grafo;

Simulação: percorrendo o grafo

A busca em largura (BFS) visita primeiro os vizinhos mais próximos, usando uma fila. A busca em profundidade (DFS) mergulha o máximo possível antes de voltar, usando uma pilha.
